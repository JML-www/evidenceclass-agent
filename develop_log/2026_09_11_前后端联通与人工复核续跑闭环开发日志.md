# 前后端联通与人工复核续跑闭环

## 2026-09-11

- 本批改动形成于 2026-09-05，此后一直以未提交状态保留在工作区；《阶段十一 AI/RAG/Agent 评测开发日志》中"核对阶段十基线：`4213fd5`，保留工作区已有未提交的前端/API/worker 接续改动"即指本批。2026-09-11 随提交 `bff8792` 提交并推送，远端 `main` 与本地一致。
- 主题：把 Web 前端从纯 Mock 边界接到真实 API，并把"人工复核 → 决策 → 续跑"这条链路真正打通——此前 review 决策只落库，不驱动 Agent Run 从检查点继续。
- 规模：17 files changed，+651 / −120。

## 产品 API（`apps/api`）

- 新增 `POST /api/v1/auth/register`：一次创建 user + workspace + OWNER 成员并直接返回 token；校验邮箱格式与密码长度（≥8），重复邮箱返回 409。
- 新增 `GET /api/v1/jobs/{job_id}/artifacts`（`ArtifactResponse`）。
- 新增 `DELETE /api/v1/conversations/{conversation_id}`（204）。
- 新增 CORS 中间件，放行来源由 `EVIDENCECLASS_CORS_ORIGINS` 配置（默认 5173），前后端分端口联调所必需。
- `JobResponse` 增加 `title`，由 `metadata.title` / `goal` 推导，任务列表不再只显示 UUID。
- 资产与产物响应增加 `download_url`（预签名下载）。
- `decideReview` 从"只改状态"改为：调用 `JobLifecycleService.resume_after_review()`，按返回结果投递 Outbox；响应体增加 `resumed` / `task_id`。

## Worker（`apps/worker`）

- 新增 `RuntimeWorker.resume(run_id, decision)`：从最近检查点恢复执行，`resume_node = "compute_metrics"`。
- 新增 `_publish_structured_result()`：structured 模式完成后产出 5 类产物 —— `dashboard.html`、`report.md`、`evidence.csv`、`actions.csv`、`analysis_result.json`，并写入 `EvidenceItem`。
- 新增 Celery 任务 `evidenceclass.resume_agent`；`CeleryTaskQueue` 与 `InProcessTaskQueue` 均实现 `enqueue_resume`，离线与在线路径语义一致。
- `runtime_bootstrap` 按配置装配 MinIO 或内存对象存储；`RuntimeWorker` 注入 `ObjectStorageService`。

## 契约与持久化（`packages`）

- `agent_runtime/state_machines`：新增 `REVIEW_REJECTED` 事件与 `NEEDS_REVIEW → FAILED` 迁移——复核被拒即终止，不再续跑。
- `object_storage`：新增 `read_asset` / `read_artifact` / `artifact_download_url`，三者均带 workspace 归属校验，防止跨租户读取。
- `persistence/jobs`：新增 `JobLifecycleService.resume_after_review()`，原子推进 job/run 状态并写 Outbox，避免"决策已落库但任务未续跑"的中间态。

## Web（`apps/web`）

- 新增 `AuthGate` / `AuthPage` / `AppShell`：token 存 localStorage，支持注册、登录与退出；`isMockApi` 决定走真实 API 还是 Mock。
- 任务中心：新增"已取消"页签、行内操作菜单（取消 / 重试 / 重跑）、清除筛选。
- 新建分析：必填校验、可选"教学计划或转写"附件、创建后自动 `startJob`。
- Agent Run 页：SSE 实时进度 + 5 秒轮询兜底、取消 / 重新运行、错误码提示。
- 证据浏览器：标签 / 来源 / 区域 / 复核状态四维筛选、CSV 导出、复制引用。
- 复核工作台：接真实 `listReviewItems` 队列、排序、理由必填、MODIFIED 需带修订值。
- 新增展示组件 `PageHeader` / `StatusBadge` / `Citation`；`pairMessages` 把会话消息配对成问答。
- Mock 层补齐 `mockReviewItems` / `mockArtifacts`，离线演示同样能走完整操作链路。
