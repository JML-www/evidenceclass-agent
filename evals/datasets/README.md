# Stage 11 evaluation datasets

These JSONL fixtures are authorized synthetic records. They contain no private media,
production prompts, model weights, or external credentials. `manifest.v1.json` is the source of
truth for dataset and annotation versions. A record may be assigned to `dev` or `test`, but a
single media asset must never cross splits in a real dataset.

The perception fixture intentionally keeps unknown values (`null`) distinct from a zero count.
The retrieval fixture uses workspace-scoped chunk identifiers. Agent cases include forbidden
tools and terminal states so safety failures cannot be hidden by an average accuracy score.

## Tracks and what each one is allowed to claim

The perception file carries several tracks with different provenance. They are not
interchangeable, and the difference matters when reading a number:

| track | records | provenance | what it can claim |
| --- | --- | --- | --- |
| `vision_fixture` | 120 | generated by `evals/run_stage11_expand_perception.py` with `seed=20260812` | nothing about a model. The `prediction` field is a **documented synthetic observer error model**, so `real_model` is `false` and `evaluate_vision` keeps `accuracy_claimed` false. Its job is to exercise the evaluator and pin a regression baseline. |
| `asr` | 4 | manually written references over authorized synthetic speech | transcription quality on synthetic speech only |
| `ocr` | 6 | rendered synthetic slide / board / no-text frames | OCR quality on synthetic frames only |
| `structure` | 12 | schema-validity fixtures | schema conformance, not accuracy |

Two further tracks are produced by real models and live under `runs/` (git-ignored) because they
are run outputs rather than checked-in fixtures:

| track | producer | boundary |
| --- | --- | --- |
| `real_vlm_comparison` | `evals/media/run_stage5_vision_eval.py` against the local Qwen3.5-0.8B | 30 self-authored synthetic diagrams. **Not classroom accuracy.** |
| `real_asr_comparison` | `evals/media/run_real_media_eval.py --asr-backend funasr-http` against the local FunASR service | authorized synthetic speech. **Not classroom accuracy.** |

## Regenerating the fixture track

```bash
.venv/Scripts/python.exe -m evals.run_stage11_expand_perception --dataset evals/datasets/perception.v1.jsonl
```

The command is idempotent: once the vision track holds 120 records it returns them unchanged, and
the existing 30 hand-written records are never rewritten.

## Annotation agreement

`docs/evaluation/annotation-report-v1.md` records the inter-annotator agreement between two
independent automated annotators. It reports Cohen's kappa and states plainly that neither
annotator is a human, so a human double-annotation round is still outstanding.
