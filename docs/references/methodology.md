# Methodology boundary

The current metrics are descriptive characterizations, not validated measures of learning,
teaching quality, or model accuracy. Model-reported confidence is not accuracy and is never a
statistical aggregation weight. Until an independent annotated dataset and reliability study
exist, this project does not report accuracy (不报告准确率).

The evidence and validation boundary is informed by established measurement principles,
including OECD's *Measuring Improvements in Learning Outcomes* (DOI
`10.1787/9789264043466-en`) and coefficient alpha's original measurement literature (DOI
`10.1177/001316446002000104`). A citation documents the methodological boundary; it does not
validate this software's classroom metrics.
